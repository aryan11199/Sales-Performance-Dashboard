# Sales Performance Dashboard

## Project Overview
An Excel-based Sales Performance Dashboard designed to analyze sales executive performance and track daily sales targets.

## Key Features
- Daily Sales Analysis (Day 1 to Day 5)
- Total Sales Performance
- Target Achievement Percentage
- Away From Target Analysis
- Sales Executive Performance Tracking
- Region-wise Sales Analysis

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Charts and Data Visualization

## Objective
To analyze sales performance, identify top-performing executives, and monitor target achievements.
